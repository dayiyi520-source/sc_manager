# 友商管理界面规格

## 范围

在客户与商机下新增友商管理界面。本期只提供前端界面原型，不接入启信宝、招投标统计或友商写入服务，也不伪造企业档案。已登录用户可查看页面；具体编辑权限在数据服务接入时确定。

## 数据契约

- 友商档案：稳定 ID、企业名称、注册资金、法人、竞品行、创建人、创建时间。
- 竞品行：师创产品 ID、友商产品名称、资料附件元数据与链接。师创产品仅来自产品管理中标记为可销售的产品。
- 交锋项目：招投标项目 ID 与名称、核心产品、交锋结果。展示数据未来由招投标管理按友商身份关联生成；当前类型缺少友商关联，暂不推断或填充数量。
- 企业搜索候选：企业身份 ID、名称、注册资金、法人；未来经服务端代理启信宝。前端不持有第三方密钥。

## 流程与状态

列表展示八列，竞品和交锋数量为蓝色按钮，分别打开详情弹窗。新建/编辑打开宽弹窗：搜索选择企业，注册资金与法人只读，竞品行可增删，资料支持附件和链接两种编辑形态。当前企业候选为空，无法完成有效保存；取消或关闭只丢弃本次草稿。

默认使用官方空状态；候选不可用时给出明确反馈，输入保留；无可销售产品时产品选择为空；长名称在表格内省略并保留完整提示；只读弹窗与宽表单在既有主题下保持可读。禁止把演示草稿当成已保存档案。

## 验收

菜单进入、八列布局、两个详情弹窗、表单字段、竞品行增删、可销售产品过滤、附件/链接控件、只读工商字段和空数据表现均可通过组件测试与浏览器预览验证。类型检查和构建通过。
