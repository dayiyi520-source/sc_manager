# 云效风格工作项创建界面设计规格

## 1. 设计目标

将产品管理中的需求任务、研发任务、缺陷管理创建界面统一为云效工作项创建体验：用户从列表进入创建面板后，能够先明确工作项标题，再按业务上下文补充字段、关联对象和描述，最后在固定操作区提交或继续创建。

本设计只借鉴云效工作项的布局和交互范式，不复制云效品牌标识、受保护视觉资产或具体实现。页面继续使用项目现有的深色工作台 Token、8px 圆角、40px 控件高度和 Octicons 图标。

## 2. 统一页面结构

### 2.1 创建面板

- 使用大尺寸右侧抽屉，宽度约为工作区的 720px，桌面端保持主列表可见；移动端切换为全屏面板。
- 顶部固定标题栏：工作项类型、创建标题、关闭按钮。
- 主体分为两列：左侧为主要编辑区，右侧为结构化属性区。
- 底部固定操作栏：取消、保存并继续、创建工作项；提交期间按钮显示加载状态并禁止重复提交。
- 面板内容可独立滚动，顶部和底部操作栏不随内容滚动。

### 2.2 信息层级

1. 标题：第一视觉焦点，必填，单行输入，支持长文本但不允许溢出布局。
2. 工作项描述：主要编辑区，支持多行文本；需求和研发任务使用目标/描述分组，缺陷使用复现与结果分组。
3. 责任与时间：负责人、截止时间、预计工时。
4. 业务关联：产品线、版本、客户、来源需求、代码仓库或分支。
5. 属性区：状态、优先级、严重程度、工作项类型等结构化字段。

## 3. 需求任务创建

### 左侧主要编辑区

- 任务标题（必填）
- 需求描述
- 期望目标
- 验收说明

### 右侧属性区

- 状态：默认“待处理”
- 优先级：默认“P1-高优”，允许切换 P0/P1/P2/P3
- 负责人：可搜索组织成员，默认当前用户
- 完成时间：日期选择
- 预计工时：正数小时
- 关联版本：可选
- 关联产品线：可选
- 关联客户：可搜索选择
- 来源需求：可选；从工单流转创建时自动带入且只读

### 提交结果

- 创建成功后关闭面板并刷新需求任务列表。
- “保存并继续”保留当前面板，清空标题和描述，保留最近使用的产品线、版本和负责人。
- 创建成功提示已同步需求池与版本规划；失败时保留所有填写内容。

## 4. 研发任务创建

### 左侧主要编辑区

- 任务标题（必填）
- 任务描述
- 实现目标
- 技术备注

### 右侧属性区

- 状态：默认“待开发”
- 优先级：默认“P1-高优”
- 开发负责人：可搜索组织成员，默认当前用户
- 预计工时：正数小时
- 代码仓库：必选
- 目标分支：必填，默认当前研发分支模板
- 关联需求：可选
- 关联版本：可选

### 提交结果

- 创建成功后生成研发任务记录，并在任务详情中展示仓库和分支信息。
- “保存并继续”保留仓库、分支、负责人和版本选择，清空标题与描述。
- 仓库或分支无效时阻止提交并在对应字段下方显示错误。

## 5. 缺陷创建

### 左侧主要编辑区

- 缺陷标题（必填）
- 实际结果（必填）
- 期望结果（必填）
- 复现步骤（必填）
- 补充描述
- 附件入口

### 右侧属性区

- 状态：默认“待修复”
- 严重程度：默认“严重缺陷”
- 缺陷类型：功能缺陷、性能问题、兼容性问题、体验问题
- 产品线：必选
- 影响版本：必选
- 测试环境：可选
- 负责人：可搜索组织成员
- 参与人：可搜索多选
- 截止时间：可选

### 提交结果

- 创建成功后关闭面板并刷新缺陷列表。
- “保存并继续”保留产品线、版本、环境和负责人，清空缺陷内容。
- 复现步骤、实际结果或期望结果缺失时禁止提交；附件上传失败不清除已填写文字。

## 6. 交互状态与异常边界

### 必须覆盖的状态

- Normal：字段可编辑，主按钮可提交。
- Hover / Focus：控件边框提升到主色，显示可见焦点环。
- Active / Loading：提交按钮显示“创建中…”，所有提交入口禁用。
- Disabled / Error：字段显示错误文案，提交按钮根据缺失字段禁用或提交后聚焦首个错误。

### 异常边界

- 网络超时或接口失败：保留所有表单内容，显示错误提示，可重试。
- 重复点击提交：只允许产生一条记录，按钮进入加载态直到请求结束。
- 无可选负责人、客户、版本或产品线：显示明确空状态，不显示伪造选项。
- 标题或描述过长：允许继续输入但在达到限制时显示剩余字数，禁止布局横向溢出。
- 关闭未保存面板：若已有输入，二次确认后关闭；取消关闭继续编辑。
- 从来源需求流转创建：来源需求只读展示，禁止修改原始关联。

## 7. 视觉规范

- 页面背景使用 `--bg-main`，面板使用 `--bg-surface`，字段使用 `--bg-card`。
- 输入、下拉、文本域高度统一为 40px；多行编辑区最小高度 120px。
- 面板圆角 12px，控件圆角 8px，字段间距 16px，组内间距 8px。
- 主操作使用 `--primary`，次操作使用边框按钮，危险错误使用 `--danger`。
- 状态标签沿用 `StatusTag`，不使用单侧粗彩条表达状态。
- 图标统一使用 `@primer/octicons-react` 兼容入口。

## 8. 验收标准

1. 三个创建入口打开后使用同一面板骨架、顶部标题栏和底部固定操作栏。
2. 标题、描述、负责人、状态、优先级和提交反馈在三个页面中的位置和样式一致。
3. 需求任务、研发任务、缺陷的专属字段完整展示，字段默认值与现有业务规则一致。
4. 正常、聚焦、加载、禁用/错误四种状态可观察且不会造成布局跳动。
5. 创建成功、保存并继续、校验失败、网络失败和关闭未保存内容均符合本文档行为。
6. 现有列表、详情、编辑和数据保存契约不被破坏；创建成功后列表可立即看到新记录。
7. 前端 lint、测试、构建通过，三个页面在 1920x1080 下无横向溢出和遮挡。
