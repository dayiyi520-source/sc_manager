# 产研字典动态分类与字段配置设计

## 目标

将产研字典从只读概览升级为全局配置中心：管理员可以新增通用工作项分类，并分别配置新建任务、新建子任务、列表和迭代任务四个场景中的字段显示、必填与顺序。现有六个内置分类保持编码和业务兼容。

## 页面结构

- 产研字典使用 Ant Design `Tabs`，选中态为图标、蓝色文字和底部指示线，不使用胶囊背景。
- 工作项分类使用响应式 `Table`；窄屏切换为纵向信息卡。页面提供新增、编辑、启停和删除入口。
- 工作项字段采用“分类导航 + 场景 Tabs + 字段配置表”。桌面端左右布局，平板及手机端上下布局；手机端字段表转换为卡片。
- 抽屉在桌面端使用固定最大宽度，在窄屏下占满视口。

## 分类规则

- 内置分类：产品、设计、研发、测试、缺陷、用例；稳定编码保持 `requirement/design/dev/test/bug/case`。
- 自定义分类必须提供唯一稳定编码、分类名称、界面显示名称、图标、排序、启用状态和能力类型。
- 能力类型为“通用工作项”或“测试用例”。自定义分类默认使用通用工作项；测试用例能力保留现有专有逻辑。
- 内置分类不可删除。自定义分类被工作项模板、产品类型、工作项或自动化引用时不可删除。
- 停用分类不会删除历史数据，但不能继续用于新建类型和工作项。

## 字段配置规则

- 场景：`CREATE` 新建任务、`CREATE_CHILD` 新建子任务、`LIST` 列表、`ITERATION` 迭代任务。
- 每条配置包含字段编码、显示名称、字段类型、是否显示、是否必填、排序、是否系统锁定。
- 隐藏字段自动取消必填；列表和迭代场景不允许配置必填。
- 标题为新建任务和新建子任务的系统锁定字段，始终显示且必填。
- 状态、创建人、创建时间等只读字段不能进入新建场景。
- 新增分类自动生成通用字段默认配置；已有分类在首次读取时自动补齐默认配置。

## 接口与持久化边界

- 分类提供查询、新增、修改和删除能力，写操作校验租户、权限、版本和引用关系。
- 字段配置按分类查询，按单场景整体保存；后端校验字段白名单、重复项、必填规则和系统锁定规则。
- 本期保存全局预设。产品级继承和覆盖沿用已确认的后续接入边界，不在本次把现有产品批量覆盖。

## 状态与异常

- 加载时展示骨架或加载状态；空数据提供明确新增入口；失败保留重试按钮。
- 保存期间禁用重复提交；并发版本冲突提示刷新后重试。
- 删除使用 Ant Design 二次确认，并显示无法删除的业务原因。

## 验收

- 产研字典 Tabs 与参考图一致，字号不变，无蓝色胶囊背景。
- 1920×1080、平板和手机宽度下页面均无内容遮挡，核心操作可完成。
- 可以新增通用工作项分类，新增后可在工作项模板分类中选择。
- 四个字段场景可独立保存，隐藏与必填约束正确，刷新后配置保持。
- 内置分类不能删除；被引用的自定义分类删除失败并给出明确反馈。
