# 发票与回款界面视觉整改规格

## 目标与边界

发票管理和回款管理沿用现有综合中心信息结构，不改业务字段、表单提交、筛选及数据来源。统一三个页签、列表、抬头卡片、筛选与两个弹窗各自的视觉状态，明暗主题由现有 Design Token 驱动。其它综合中心模块不受影响。

## 视觉方案

采用现有专业工作台的克制表格方向：主焦点为当前页签与页面主要操作，辅助焦点为筛选和数据列表。页签使用文字与底线表示当前视图；主要操作使用品牌主色；成功、警告和危险仅表达业务状态。抬头资料卡片为紧凑的名称和字段信息布局，不使用白字浅底、额外装饰或嵌套卡片。表单标签、输入、底部操作区与列表统一 8pt 间距和固定字阶。

## 状态与范围

- 默认：两页各三个页签，数据表与抬头卡片按相同容器、边框、文字层级展示。
- 悬停/聚焦：页签、按钮、搜索与表单有清晰可见的令牌化焦点；表格行仅在有数据时反馈。
- 激活/加载：当前页签与主按钮有明确激活态；保留原有提交操作和反馈，不新增虚假加载。
- 禁用/异常/空：无数据及无匹配结果使用官方 Ant Design Empty；无效表单保留原有浏览器校验；窄屏表格允许横向滚动、表单双列折为单列。

涉及文件仅为发票和回款视图、局部样式、相关测试以及对应 PRD 说明。测试覆盖页签、抬头卡片、弹窗字段、空状态与既有提交流程，浏览器验证采用 1920x1080 网页视口。
