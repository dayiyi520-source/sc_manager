# 亮色工作区控件一致性设计

## 目标

修复亮色模式下右侧工作区仍呈现深色表面的弹窗、页内 Tab、Tab 操作按钮及表单控件，使其与既有浅灰工作区、白色内容面板和蓝色激活态一致。

## 范围与边界

- 包含：右侧工作区中的通用弹窗、产品线与版本相关弹窗、页内 Tab、分段控件、主按钮、次按钮、图标按钮、禁用按钮、表单输入与选择控件。
- 不包含：左侧主导航、二级菜单、其文字、图标、选中状态与布局。它们在亮色模式下继续保留暗色导航体系。
- 不改变路由、接口、权限、业务数据、弹窗提交行为或暗色模式视觉。

## 视觉与交互规则

亮色模式的右侧工作区以 `--bg-main` 为页面背景，弹窗主体和输入框以 `--bg-card` 为表面，分组与底栏使用 `--bg-surface-soft`。正文使用 `--text-primary` 和 `--text-body`，边框使用 `--border-main` 或 `--border-subtle`。

主按钮保持品牌蓝和白色文字；次按钮、取消按钮和图标按钮采用白色或浅灰表面、深色文字和可见边框。页内 Tab/分段控件使用浅灰蓝容器，当前项为白色表面与品牌蓝文字，未选中项 hover 时强化为浅蓝灰。焦点态使用主色边框与低强度外环；禁用态保持可识别但不可点击；表单校验错误不得因主题切换降低文字或边框对比度。

## 实现边界

在全局亮色主题层中定义只作用于 `.tech-main` 和工作区弹层的覆盖规则，替换当前仅挂在 `.product-line-detail` 下的局部适配。组件保留现有 className 和行为，以主题令牌集中处理遗留深色 utility class，避免跨页面逐个复制颜色规则。

## 验收

在 1920x1080 亮色模式下验证产品线新建弹窗、版本创建/编辑弹窗、成员管理弹窗和版本迭代页：

1. 弹窗标题、主体、底栏、输入框、下拉和取消/保存按钮均为亮色体系，文本可读。
2. 页内 Tab、选中 Tab 和其操作按钮具有一致的默认、悬停、聚焦、禁用/异常反馈。
3. 长标题与空列表不溢出、不遮挡固定操作区。
4. 暗色模式与左侧导航的既有外观和交互不变。
