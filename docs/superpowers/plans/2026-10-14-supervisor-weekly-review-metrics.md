# 主管周复盘指标与六部分表单实施计划

目标：主管进入周复盘即可查看部门进度、提交人数和待确认风险，按六部分填写并保存。

约束：沿用 React、Ant Design、Octicons 与 AIEDIT Token；保留员工模板；默认 Empty；不新增依赖。用户指定了页面结构，按局部调整执行。

1. 从现有部门目标、直属员工、本期已提交复盘与查看记录汇总三项指标，缺少历史沿用现有进度基线。
2. 调整顶部部门周复盘标识及六个章节，新增总结输入并保存至既有总结字段，验证只读详情回显。
3. 更新需求 1.1.33，增加相关组件和统计测试，运行 TypeScript、相关 Vitest、构建及 PRD 校验。

边界：无目标或无员工、同人多份报告、跨期和非直属人员、风险记录已查看、数据加载失败、保存忙碌及只读、超长文本。
