# 项目质量优化实施计划

## 目标

按已确认顺序降低高优先级维护风险：统一 Design Token 与 Ant Design API，修正项目配置漂移，核对数据库迁移状态，并优化生产构建分包。

## 范围与边界

1. 仅修复已确认的弃用 API、主题入口硬编码和可安全迁移到 CSS Token 的页面样式；不机械改写 SVG 插画与历史兼容样式。
2. 将企业配置改为与实际 React/Vite 根目录一致，不创建虚假的 frontend 应用目录。
3. 只依据仓库源码、构建产物和 Git 历史核对迁移版本，不臆造缺失 SQL，不连接或修改生产数据库。
4. 调整 Vite 分包并通过构建产物验证，不改变路由和业务 API。
5. 完成 typecheck、测试、构建、服务健康检查和浏览器验收后，尝试创建本地 feature checkpoint；若仓库缺少脚本则明确记录阻塞原因。

## 验收标准

- 不再使用本轮涉及的 Ant Design 弃用属性。
- Ant Design 主题颜色通过 AIEDIT CSS Token 获取。
- 配置中的 frontend framework/root 与仓库实际结构一致。
- 迁移源码、构建产物和远程分支的最高版本差异有明确结论。
- 生产构建无 circular chunk 警告，最大 chunk 有可解释的拆分结果。
- 既有测试与新增静态检查通过，前后端健康检查正常。
