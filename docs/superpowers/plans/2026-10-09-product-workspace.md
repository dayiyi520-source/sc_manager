# 产品详情与任务视图实施计划

目标：按用户提供的六张截图调整产品设置、产品文档和研发/测试上游产品任务视图。保留项目现有主题、权限入口和数据访问层，不新增依赖。

- [x] 产品详情保留顶部导航；在产品迭代后增加产品文档，在产品效能后增加产品设置。责任人配置移入设置，三类主责任人必填，次责任人可空，同职责不能重复。
- [x] 独立文档组件：三分类，每类一份当前文档；复用产品配置保存和富文本编辑器。文件限制 1MB，读取失败、空内容及存储失败保留原文档和编辑内容；替换、删除确认；安全阅读与下载。
- [x] 独立产品任务视图：通过现有工作项查询分页获取产品任务和研发/测试关联，按当前产品筛选显示分配状态；详情复用现有产品任务详情入口。
- [x] 更新现有产品管理需求章节；运行类型检查、针对性测试、构建和 PRD 校验，报告既有校验问题。

数据约定：ProductLine.documents 按分类保存名称、来源、正文或文件内容、大小、操作人和更新时间；工作项分配依据 requirementId 或 parentWorkItemId，不根据标题推断。
