# Supervisor review progress implementation plan

**Goal:** 员工工作台展示 KR 与本人动作；主管复盘支持本人承接进度和证据；复盘卡显示部门 O 加权进度。
**Architecture:** 复用目标记录、复盘汇总与证据选择器；新增本人进度输入仅对明确指派本人 KR 生效，提交重新计算并保存部门进度快照。
**Tech Stack:** React、TypeScript、Ant Design、React Query、Vitest。
**Spec:** 本会话已确认的四项要求。

- [ ] 目标映射：优先本人个人承接，读取当前来源 KR 和本人动作；验证部门 O 与其他人动作不混入。
- [ ] 本人进度：为明确指派主管的 KR 保存每行本人进度，合并员工支撑，提交时再次校验；测试多人平均、只读、撤销指派和保存重开。
- [ ] 本人证据：复用选择器，员工证据下方展示本人证据；验证选择、删除、保存、历史读取。
- [ ] 部门进度：按 KR 权重计算 O，再按 O 权重汇总，草稿与提交保存快照；卡片读取快照，历史缺失显示未记录。
- [ ] 更新对应 PRD，运行定向测试、类型检查、构建和差异检查；保留已有修改。
