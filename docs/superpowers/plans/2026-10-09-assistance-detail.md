# 协同事项详情与验收闭环

目标：协同事项详情字段与新建一致，并建立待处理、处理中、待验收、已完成、已退回闭环；任务空态按已提供截图提供新增入口。

1. 保留基础字段、事项描述、附件、关联任务、事项全历程结构；关联任务无数据时展示居中空状态与“新增第一个任务”操作。
2. 状态仅展示待处理、处理中、待验收、已完成、已退回。待处理由负责人接收后进入处理中；转交待处理事项不改变状态。
3. 处理中负责人可提交事项完成，负责人固定为创建人；存在未完成关联任务时禁用。完成进入待验收；验收通过进入已完成，验收未通过需填写原因并回到处理中。
4. 服务端校验当前状态、负责人、版本、租户和任务完成情况，所有变更记录事项历程；接口并发冲突应返回可恢复错误。
5. 更新 PRD 需求编号 1.2.44，覆盖正常流转、权限不足、空任务、未完成任务、提交失败和重复提交边界。
6. 运行前端相关 Vitest、类型检查、构建、后端针对性 Maven 测试、PRD 校验和 diff 检查；不创建本地 checkpoint，除非所有验证通过且变更路径无其他用户改动。
