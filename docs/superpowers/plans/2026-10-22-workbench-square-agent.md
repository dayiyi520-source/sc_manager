# 工作台信息分流与代理商待办实施计划

**目标**：按用户确认方案调整首页，产品发布只读同步，信息广场支持组织部门范围，代理商首页对接培训。
**确认**：2026-10-22 用户确认；不包含全员或成员选项，产品动态默认师创组织。
**架构**：复用 MyTasksView，代理商以页面参数替换审批卡；信息分类、组织范围、版本同步分离为服务，列表与卡片共用权限及已读状态。
**技术**：现有 React / TypeScript / Ant Design / Octicons / Mock 持久化，不增加依赖。

- [x] 建立组织及部门范围契约：组织 ID、部门路径；旧用户默认师创组织，同名部门按组织隔离，范围必填且不含成员。
- [x] 信息分类迁移、标签及可选关联保存；旧指定成员记录保留原限制，编辑需改选组织部门；同步来源禁止在工作台编辑删除。
- [x] 已发布版本同步为产品动态，保持版本标识、发布时间、去重及只读，完成迭代不等同发布。
- [x] 拆分首页卡片、目标百分比与月度目标跳转、新增代理商待办及学习卡片和课程跳转。
- [x] 完整列表两标签与详情/编辑器调整，保留搜索、分页和单用户未读状态。
- [x] 更新现有编号 PRD，验证范围隔离、失败重试、存储异常、刷新恢复、发布同步和培训跳转，运行测试、类型检查、构建及 1920×1080 浏览器核验。

数据契约：WorkbenchFeed.type 为 dynamic/square，兼容历史 feedback/competitor；tags 为非空字符串数组；audienceScopes 为组织/部门路径数组；source 保留来源记录身份。CurrentUser / EmployeeOption 的 organizationId 可选，历史省略时为 shichuang。信息保存统一经服务校验。
