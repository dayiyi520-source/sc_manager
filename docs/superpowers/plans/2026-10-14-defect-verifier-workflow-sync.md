# 缺陷验证者与工作项模板同步实施计划

**Goal:** 支持真实验证者、个人验证筛选及全公司范围，修复产品与模板状态流程不一致。
**Architecture:** 复用共享任务表单与 API 契约，使用幂等迁移同步产品模板和历史任务绑定。
**Tech Stack:** React、Ant Design、现有 Mock 持久化与 Vitest。

- [x] 表单验证者紧跟负责人，使用在职成员 ID 与姓名，历史缺陷补齐。
- [x] 缺陷标签加入待我验证和全公司，计数与筛选共用同一规则。
- [x] 产品同步系统模板，保留有效状态，修复失效类型和流程；重复读取不得改写用户状态。
- [x] 验证无可用成员、模板状态被移除、并发保存与重复迁移边界。
- [x] 更新对应 PRD、运行相关测试和构建，仅提交本次变更。

验证记录：相关测试、类型检查和构建完成；PRD 校验仍报既有字段类型术语及登记数量不一致。
