# 售前与交付任务入口及列表计划

目标：新增客户与商机／售前任务、项目管理／交付任务入口，按用户给定字段展示并支持三个带完整数量的范围标签。

实施范围沿用当前 React、Ant Design、主题变量和现有业务任务接口。默认我负责的；我创建的按创建人匹配；我部门的按任务部门或负责人所属部门匹配，没有部门时为空。各标签数量不受分页与临时搜索影响。

数据契约：复用 RequirementTask 与 PageResult。来源取已有项目、客户及 specialFields 归属信息；交付阶段优先取任务归属信息，缺失时取关联项目阶段。缺失归属不冒充产品或版本。分页读取完整可访问集合并按 ID 去重；读取失败提示重试，禁止把部分集合当作全部。

1. 在 AppContext 中恢复两个菜单组，每组仅添加指定任务入口；更新导航回归测试。
2. 抽取业务任务分页读取、范围判断和来源展示工具；接入 RequirementTasksView 的查询、刷新和三标签计数；固定售前八列、交付九列。保留原有详情与创建流程。
3. 为现有 mock 模式补齐售前和交付独立持久化存储、详情、创建、更新、评论和动态；真实模式沿用已有接口。测试跨页计数、同名身份、部门缺失、归属缺失、异常重试、保存后的刷新。
4. 在现有应用壳与导航需求内更新 PRD，并运行 PRD 校验、相关 Vitest、TypeScript、构建。

视觉：沿用 AIEDIT 暗色工作台，列表标题为主焦点，范围计数和来源为辅助信息。复用主题变量、键盘焦点和现有按钮反馈；按用户2026-10-12补充要求，空态与其他任务列表统一使用纯文字，不展示插画。长文本截断并保留完整提示，表格横向滚动。

边界：空任务、无部门、无关联对象、长名称、跨多页、请求失败、重复保存、更新后归属切换。已有未提交的月度目标改动和 PRD 内容须保留；PRD 与用户改动共享时不创建包含其内容的 checkpoint。

## 2026-10-12 任务样例与关联区调整

在 src/data/mockBusinessTasks.ts 提供售前与交付各8条稳定样例，覆盖不同范围、状态、优先级、商机或招投标来源及项目阶段。通过独立 seedVersion 仅追加缺失样例，保留已有任务与同标识样例的编辑结果。生产模式不引用本地样例作为数据来源。

售前和交付新建固定保留协同事项与关联任务，详情固定按动态、协同事项、关联任务展示，其他任务分类继续沿用原规则。复用原关联读写契约，不改变关系数据。验证样例数量和独立存储、首次迁移、重复读取、编辑保留、明确空数组，以及两个任务新建和详情入口。更新1.1.58后运行相关测试、类型检查、构建及PRD校验。
