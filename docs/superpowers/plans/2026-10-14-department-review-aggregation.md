# 部门周报汇总与个人复盘展示实施计划

目标：员工子表进度驱动部门子表、KR 与 O，统一个人复盘列表详情与新表单；主管展示员工支撑及三类下级内容。

规则：员工等权平均形成一行；子表行等权平均形成 KR；KR 权重形成 O。未提交延用上次已提交值，无历史为零。只纳入直属员工、明确对齐、当前周期目标。草稿仅预览，正式提交由提交处理层重新计算并同步。

1. 新增可测试的聚合服务，复用现有支撑过滤，保存子表和来源快照。
2. 调整主管 KR 卡片和员工表、内容汇总及标题；移除月报周证据时间轴。
3. 个人历史卡片及只读详情按新字段展示，历史填过字段保留为历史补充。
4. 更新 PRD 1.1.33、测试计算/隔离/草稿不写/正式提交同步及 UI；类型检查、构建和 PRD 校验。

边界：记录缺失、未提交、多人多动作、子表无权重、无子表、零权重、同名内容不同身份、权限及版本冲突。生产后端不在本仓库，交付不声称生产数据库已验证。


验证记录：核心 10 文件 / 62 项通过，主管工作台入口专项 1 项通过；类型检查及构建通过。广范围工作台测试另有 8 条目标导航及旧表单断言未通过，不修改无关功能。浏览器会话已失效跳登录页，已恢复 3012 前端服务；已登录页面视觉验收未完成。PRD 仍存在原有字段类型与登记数量校验问题。生产后端不在本仓库，同步持久化仅验证本地接口。共享文件含其他未提交改动，不创建 checkpoint。
