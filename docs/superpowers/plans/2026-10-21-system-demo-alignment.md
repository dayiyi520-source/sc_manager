# 系统权限与工作流演示更新计划

1. 对照协同事项、待办、动态、交付任务和 OKR 的现有权限函数及 Mock 规则，删除无依据的部门授权矩阵和旧状态路径。
2. 权限演示按业务对象、当前操作身份和记录状态展示结果；复用现有负责人、创建人、交付审核、动态可见和 OKR 授权判断。读取实际目标设置及人员，提供加载、失败重试和无人员反馈，禁止写业务数据。
3. 工作流演示提供协同闭环、验收退回、转派、已退回事项、独立任务、交付审核、目标确认、复盘、动态阅读场景。支持上一步、下一步、重置；配置任务流程读取真实工作项模板并展示允许路径，不伪造测试状态。
4. 同步编号需求及字段表，补权限与步骤回归，运行类型检查与构建；保留既有 Mock 数据改动，不自动提交和部署。

边界：只读演示；空配置使用默认空状态；读取失败明确重试；旧版记录身份缺失按现有函数兼容；演示切换不调用保存接口。
