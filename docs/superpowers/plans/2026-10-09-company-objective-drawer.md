# 公司级月度目标抽屉调整实施计划

**Goal:** 按已确认参考图调整公司目标编辑与详情，沿用现有主题和持久化接口。

**Architecture:** ObjectiveForm 保留 A 编辑与校验，将 O 类型、备注及权重作为独立字段保存；工作区使用底部 Drawer 包装公司新增与草稿。公司只读详情独立组件复用真实目标树计算、任务数据及动态查询，主管和个人详情保持原流程。

**Tech Stack:** React 19、TypeScript、Ant Design、TanStack Query、Octicons、Vitest。

**Spec:** 用户确认的三项界面要求、两张参考图及现有需求 1.1.33。

## 约束与契约

- 不新增依赖，保持现有 API 层；使用 OkrPayload 的 objectiveType、weight、note、keyResults 与 OkrRecord/OkrWork。
- 公司对齐展示所选周期，不生成虚构上级 ID。首个 O 默认 target（CO），追加 O 默认 challenge（TO）；已有记录保留保存类型。
- O 权重独立于 A 权重；A 权重仍在直属 O 下合计 100%。
- 长标题换行；保存失败保留输入；忙碌时禁止重复提交和关闭；无动态或任务显示真实空态。
- 使用现有颜色变量，CO 蓝色、TO 使用主题橙色 token；编辑与详情从底部进入，固定标题/操作区域。
