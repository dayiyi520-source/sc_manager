# 全局视觉统一实施计划

**目标：** 统一 React 工作台各模块的筛选器、表单控件、列表工具栏、状态标签、弹窗和图标视觉。

**架构：** 以现有 CSS Token 和 common 组件为唯一视觉基线；先通过全局控件基线消除页面内联样式差异，再迁移核心页面到公共组件，最后分批替换图标和特殊组件。

**技术栈：** React 19、TypeScript、Vite、Tailwind CSS 4、@primer/octicons-react。

**范围：** 客户档案、线索、商机、工单、需求池优先；其他模块共享全局控件规则并建立后续迁移清单。

## 任务

- [x] 扩展 `index.css` 的表单控件、按钮、表格和焦点状态 Token，覆盖普通、悬停/聚焦、加载、禁用/错误。
- [x] 强化 `ListToolbar` 与 `Pagination`，统一搜索框、筛选下拉、操作按钮高度和间距。
- [x] 让客户、线索、商机、工单、需求池及其他工作区页面的原生控件继承公共样式。
- [x] 将 `CRMFollowupTimeline` 的左侧彩色边框改为规范分隔线，并清理核心页面中的旧浅色控件样式。
- [ ] 将仍直接依赖 `lucide-react` 的 57 个页面分模块迁移到 Octicons；本批已完成公共列表工具栏和分页入口。
- [ ] 更新 PRD 变更记录，执行前端 lint、test、build、diff check 和 1920x1080 浏览器验收。

## 验收

- 同一页面及跨客户/工单/需求池的下拉筛选高度、颜色、边框、焦点环一致。
- 控件在正常、聚焦、提交中、禁用/错误状态下均有明确反馈。
- 核心页面无新增控制台错误，构建和测试通过。
