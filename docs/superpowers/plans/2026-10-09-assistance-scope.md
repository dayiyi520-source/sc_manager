# 协同事项范围筛选实施计划

目标：按用户明确的五类范围展示事项，默认我创建的，全公司的可筛选负责人所属部门。

- [ ] 提取范围判定；以员工目录判定当前负责人部门，以本人转交活动判定参与；无目录或重名不猜测部门。
- [ ] 复用事项列表与审计活动的既有分页接口，读取完整结果；失败提示并允许重试，卸载后不更新状态。
- [ ] 更新标签和计数，部门筛选仅全公司的生效；切换范围清空部门并返回第一页。
- [ ] 验证转交后又转回本人、仅抄送、跨部门负责人、无部门及超过一页的情形；更新需求 1.2，运行相关测试、类型检查和构建。

约束：不增加依赖、不改生产权限、不提交共享未提交文件。现有租户及读取权限保持。
