# 目标与绩效本地验收

日期：2026-09-14。需求：7.1。

## 访问

- 页面：http://127.0.0.1:3011
- 后端：http://127.0.0.1:8081
- 独立 MySQL：本机 3307；数据库 `manage_admin_okr_acceptance`。
- 使用现有开发登录账号按钮 `tech`（员工）和 `admin`（直属主管），打开“目标与绩效”。登录页先拉下台灯拉绳。
- 服务登记在 `.enterprise-app-factory/runtime/services.json`；管理入口 `.enterprise-app-factory/bin/local_services.py`。
- 验收 JAR 单独保存于本地 runtime，避免 Maven 构建覆盖运行文件。Vite 忽略本地 runtime 与后端构建产物，避免 Windows 文件占用导致监听进程退出。

## 业务检查

1. 员工新增目标，未选直属上级目标时不能保存；KR 权重合计必须为 100%。
2. 员工提交，主管在下属目标中确认。刷新后状态、引用与进度仍保留。
3. 在“任务与工单”将实际工作关联至执行中 KR；复盘归集时自动带入关联。
4. 复盘分别展示各目标和 KR 的进展，以及计划外工作；填写产出、受影响目标和 KR、延期说明。
5. 员工提交后主管可退回或确认，选择计入的计划外贡献并评分；员工不能自行确认或伪造主管评分。
6. 提交快照不随后续目标进度修改而变化；并发旧版本请求返回冲突。

## 组件与入口优化验收

- 顶部“关联任务 / 工单”和个人目标详情按钮均可进入工作关联页；操作为“关联 KR → 支撑目标 → 支撑 KR → 保存关联”。这里管理已有工作项的目标关系，不替代原任务创建和流转页面。
- 下属新增目标时可自主切换上级候选，候选限定同月直属上级执行中目标；组织根负责人显示无需上级引用的说明。
