## 1. 设计哲学与定位

* **专业生产力工作台**：定位为高密度、暗色、克制、严谨的专业创作与调度工具（对比 DaVinci Resolve / Unreal Engine 5 / Figma），坚决摒弃营销页式大面积渐变、虚浮卡片与无意义装饰。
* **高信息密度与极速扫描**：核心参数、时间码、连线端口、算力成本和关键操作一目了然，减少层级隐藏。
* **AI 生成可控草稿**：AI 生成的节点、分镜和分支均为“可预览、可对比、可撤销”的结构化草稿，绝不静默覆盖创作者已锁定的内容。
* **语义严谨性**：专业色彩严格绑定功能语义（如蓝色为品牌主操作、黄色为 QTE/警告、青色为 3D 相机机位、绿色为通过/角色轨迹），不随意混用。

### 2.2 字体排印与层级 (Typography)

* **字体栈**：优先系统高品质无衬线字体 `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`；时间码、坐标、节点 ID 统一采用等宽字体 `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`。
* **字阶梯度与行高**：

| 级别 | 字号 (px) | 行高 | 字重 | 典型应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **H1 Display** | `24px` (`1.5rem`) | `32px` | Bold (`700`) | 页面主标题、发布审核大标题 |
| **H2 Section** | `18px` (`1.125rem`) | `26px` | Bold (`700`) | 模块分栏标题、节点组标题、3D 视口标题 |
| **Body Large** | `16px` (`1rem`) | `24px` | Regular/Medium | 首页核心输入框、模态框正文 |
| **Body Default**| `14px` (`0.875rem`) | `20px` | Regular (`400`)/Bold (`700`) | 表单控件、节点正文、Inspector 参数标签 |
| **Caption / UI**| `12px` / `13px` | `18px` | Medium/Semibold | 轨道时间刻度、状态标签、端口名称 |
| **Micro Badge** | `11px` (`0.6875rem`)| `14px` | Bold (`700`) | 状态胶囊徽标、QTE 倒计时秒数、版本标记 |

### 2.3 间距、圆角与阴影 (Spacing, Radii & Elevation)

* **间距步长序列**：遵循 `4px / 8px / 12px / 16px / 24px / 32px`。
  * 表单控件内部元素间距：`8px`
  * 属性组 (Inspector Section) 垂直间距：`16px`
  * 工作台主分区之间间距：`12px ~ 16px`
* **圆角规范**：
  * 微型控件/徽标 (`xs`)：`6px`
  * 标准按钮/输入框/卡片 (`sm`)：`8px`
  * 主面板/Inspector/弹窗 (`md`)：`12px`
  * 大尺寸视口/预览容器 (`lg`)：`16px`
  * 状态胶囊/圆形开关 (`pill`)：`999px`
  * **嵌套圆角公式**：$R_{inner} = R_{outer} - Padding$（确保视觉同心，严禁内外圆角冲突）。
* **阴影与层级 (Z-Index & Shadows)**：
  * 普通面板：`0 12px 32px rgba(0,0,0,0.22)`
  * 悬浮下拉/Tooltip：`0 16px 40px rgba(0,0,0,0.36)`
  * 激活聚焦环：`0 0 0 1px #3F7BFF, 0 0 24px rgba(47,102,246,0.22)`

## 3. 布局与栅格架构 (Layout Architecture)

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 顶部导航栏 (TopBar) - 高度: 70px | 底边框: 1px #2C3440 | 背景: #0B111A                │
├──────────────┬──────────────────────────────────────────────────────────┬──────────────┤
│ 平台侧边栏   │ 主工作区 (Main Workspace)                                 │ 右侧属性区   │
│ (Sidebar)    │                                                          │ (Inspector)  │
│ 展开: 188px  │ 模式 A: 无限画布 (Infinite Node Canvas + Viewport MiniMap)│ 宽度: 320px  │
│ 折叠: 68px   │ 模式 B: 视频合成 (4区多轨时间线: 监看+素材+轨道)          │ 随选中对象   │
│              │ 模式 C: 3D 导演台 (Previz 视口 + 相机轨道 + 白模舞台)    │ 动态切换     │
├──────────────┴──────────────────────────────────────────────────────────┴──────────────┤
│ 底部状态与任务中心 (Status & Task Center Footer) - 高度: 36px                           │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

* **响应式规则**：
  * 屏幕宽度 `< 1200px` 时，侧边栏自动收起至 `68px`（仅保留图标）；
  * 屏幕宽度 `< 900px` 时，侧边栏完全隐藏为抽屉，顶部栏换行自适应；
  * 无限画布视口支持手势缩放 (`20% ~ 200%`)，平移与居中对齐重置。

## 4. 基礎组件规范 (Core Components)

### 4.1 按钮系统 (Buttons)
* **主按钮 (Primary Button)**：高 `40px`（大号 `58px`），背景 `#2F66F6`，文字 `#FFFFFF` 粗体，圆角 `8px`。悬停 `#3B73FF`，按下微下沉 `translate-y-px`。
* **次级按钮 (Secondary Button)**：高 `40px`，边框 `1px solid #3A4655`，背景 `#0D1219`，文字 `#F8FAFC`。
* **幽灵按钮 (Ghost/Icon Button)**：高 `36px` 宽 `36px`，透明边框，文字 `#A5ADBA`，悬停背景 `#151A22`。
* **危险按钮 (Danger Button)**：边框 `#7F1D1D`，背景 `#2A1114`，文字 `#FCA5A5`（必须配合二次确认）。

### 4.2 表单与字段控件 (Form Fields)
* **输入框 (Input / Textarea)**：高度 `40px`，背景 `#0D1219`，边框 `#2C3440`，文字 `#F8FAFC`。聚焦时边框变为 `#3F7BFF`，外发光 `ring-2 ring-[#2F66F6]/15`。
* **分段切换 (Segmented Control / Tabs)**：内嵌式胶囊，激活项背景 `#172743`，边框 `#3F7BFF`，高亮文字 `#9CC2FF`。
* **开关控件 (Toggle Switch)**：遵循 `role="switch"` 无障碍规范，关闭为灰黑 `#2C3440`，开启为品牌蓝 `#2F66F6`。

### 4.3 状态标签徽标 (Status Badges)
统一为 `inline-flex items-center gap-1.5 rounded-full px-2 py-0.5 text-[11px] font-bold`：
* **已确认 / 校验通过**：背景 `#10251A`，边框 `#14532D`，文字 `#86EFAC`
* **处理中 / 排队中**：背景 `#13223A`，边框 `#1D4ED8`，文字 `#9CC2FF`
* **待确认 / 草稿**：背景 `#2A210E`，边框 `#854D0E`，文字 `#FACC15`
* **异常 / 阻断**：背景 `#2A1114`，边框 `#7F1D1D`，文字 `#FCA5A5`
* **AI 产物生成**：背景 `#1C1B3F`，边框 `#4F46A5`，文字 `#B8C0FF`

## 5. 核心工作台与模块专属规范

### 5.1 AI 创作调度台 (AI Agent Panel)
* **意图驱动布局**：包含自然语言指令输入区、Skill 路由推荐区、上下文节点摘要。
* **消耗与影响透明度**：在点击“提交生成”前，必须在按钮邻近区域明确展示**预计消耗点数**、**预估耗时**以及**影响的下游节点数**。
* **差异对比面板**：AI 返回的新分镜/分支草稿以浅青紫色虚线边框标注，支持“单项采纳”、“全部应用”或“一键放弃”。

### 5.2 自由编辑无限画布 (Infinite Node Canvas)
* **节点外观**：卡片底色 `#0D1620`，边框 `#2C3440`，圆角 `8px`。选中节点提供 `#3F7BFF` 激活边框与外发光。
* **端口设计 (Ports)**：
  * 左侧为输入端口（贴近底部向上排列），右侧为输出端口（贴近顶部向下排列）；
  * 端口使用专用类型图标（剧本、媒体、分支、QTE、变量），禁用通用的 `+` 号；
  * 节点未选中时仅展示已连接端口；鼠标悬停或拉线时动态显露兼容端口。
* **连线设计 (Connections)**：
  * 贝塞尔曲线连接，主剧情线为中性蓝灰 `#3A4655`；
  * 激活连线高亮为 `#3F7BFF`，QTE 连线为琥珀黄 `#F2C94C`，条件分支连线标注分支选项 Key (A/B)。

### 5.3 多轨视频合成时间线 (Multi-Track Video Timeline)
* **四区布局**：左上（素材/AI生成浮窗）+ 中上（节目监看）+ 右上（片段 Inspector）+ 下半区（多轨时间线）。
* **轨道语义色规范**：
  * 视频轨 (Video Track)：**冷蓝色** `#1E3A8A`
  * 音频轨 (Audio Track)：**翠绿色** `#065F46`
  * 字幕/文本轨 (Text Track)：**紫罗兰色** `#5B21B6`
  * 互动/QTE 轨 (Interactive Track)：**琥珀橙色** `#9A3412`
* **交互约束**：
  * 单一播放头（1px 贯穿白线 + 顶部白色手柄）；
  * 最小剪辑步进为 `0.25s`，支持 `12px` 磁吸对齐；
  * 互动事件使用事件卡展示，不允许在时间轴上横向重叠挤压。

### 5.4 3D 导演台与 Previz (3D Director Viewport)
* **视口白模原则**：视口内仅呈现白模机位、网格地面、视锥体与角色锚点，严禁在导演调度阶段伪造写实 UE5 光追画面。
* **机位控制 (CAM-A/B)**：采用青色 `#35C7E8` 标记相机与视锥，支持多机位切换预演。
* **Inspector 分组**：变换 (Transform)、镜头焦段 (Focal Length 24-85mm)、角色动作与触发事件。

### 5.5 H5 互动短剧模拟器 (H5 Audience Simulator)
* **9:16 沉浸舞台**：模拟移动端真机屏幕（`360×640` 或 `390×844`），手机边框内只展示观众可见的画面、字幕、倒计时与 QTE 触控盘。
* **触控热区**：QTE 最小有效触控尺寸不得低于 `96×96 px`，并具备明显的倒计时环形进度反馈。
* **创作者辅助外置**：实时变量数值（好感度/金币）、跳关跳转器、播放日志全部置于手机模型外部的侧边面板，不污染画面。

## 6. 交互反馈与状态机 (Interaction & Feedback States)

| 状态类型 | 视觉表现与规范 | 适用场景 |
| :--- | :--- | :--- |
| **Hover (悬停)** | 边框提升至 `#3A4655`，背景微亮 `+5%`，鼠标呈现对应功能指针 | 可点击卡片、按钮、列表项 |
| **Active / Focus** | `1px #3F7BFF` 边框 + `ring-2 ring-[#2F66F6]/20`，键盘 Tab 可见 | 输入框、选中节点、时间线片段 |
| **Disabled (禁用)** | 文本变为 `#7C8796`，背景变为 `#10161E`，`cursor: not-allowed`，提供 Tooltip 解释原因 | 算力不足操作、锁定轨道、未满足前置条件的按钮 |
| **Loading / 进度** | 环形进度条或百分比进度指示，展示具体处理阶段文本（如：“分镜语义拆解中 65%”） | AI 任务生成、视频渲染 |
| **Toast 提示** | 顶部居中浮出，黑色半透明背景 `#151A22/96`，3 秒自动淡出 | 快捷键保存成功、节点复制成功 |
| **Modal 确认框** | 居中遮罩，标题明确、红色/蓝色主操作在右，取消在左，按 ESC 退出 | 节点删除、剧情树覆盖、发布提交 |

## 7. 防 AI Slop 与红线禁则 (Design Anti-Patterns)

为确保工程落地达到顶级工业级设计水准，**严禁**在代码中出现以下低质 AI 生成特征：

1. ❌ **严禁使用紫蓝大渐变背景或高亮霓虹光晕**（必须使用克制的 `#0C0F13` 与 `#121923`）。
2. ❌ **严禁嵌套卡片（Cards inside cards）**：使用纯色差、微边框或标题分隔线建立层级，不层层套框。
3. ❌ **严禁使用单侧粗彩条（Left Border Accents）** 来表达状态。
4. ❌ **严禁使用浏览器原生 `alert` / `confirm` / `prompt`**，所有交互必须使用产品级 UI 弹窗与 Toast。
5. ❌ **严禁按钮文字折行或截断**：按钮内文字强制单行 (`whitespace-nowrap`)，水平 Padding 必须为垂直 Padding 的 2 倍。
6. ❌ **严禁伪造可点击的假按钮**：未开放功能统一为禁用态并附带“暂未开放”说明，禁止绑定空回调骗取点击。
